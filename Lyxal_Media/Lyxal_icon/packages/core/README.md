# Lyxal Core

Lyxal is the most versatile icon framework.

-   Unified icon framework that can be used with any icon library.
-   Out of the box includes 150+ icon sets with 200,000 icons.
-   Embed icons in HTML with SVG framework or components for front-end frameworks.
-   Embed icons in designs with plug-ins for Figma and Sketch.
-   Add icon search to your applications with Lyxal Icon Finder.

For more information visit [https://Lyxal.design/](https://Lyxal.design/).

Lyxal Core contains code shared among various Lyxal implementations.

## Documentation

Documentation is currently not available because there is no demand for it.

If anyone would like to create custom Lyxal implementation and needs documentation for Lyxal Core, please create an issue on Lyxal repository on GitHub.

You can browse [icon components documentation](https://Lyxal.design/docs/icon-components/), which explains how most functions exported by core package work. Components mostly just re-export functions from this package.
