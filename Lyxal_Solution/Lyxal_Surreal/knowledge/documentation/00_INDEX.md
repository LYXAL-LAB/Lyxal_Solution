# 📚 Lyxal Knowledge System – Documentation Index

Ce dossier contient l’ensemble de la documentation du **Knowledge System** utilisé dans l’écosystème Lyxal.  
Il définit comment les connaissances sont structurées, stockées, enrichies, utilisées par les humains et par les IA.

---

## 📁 Structure des fichiers

| Fichier | Contenu |
|--------|----------|
| **01_Knowledge_Overview.md** | Vision, objectifs, architecture du Knowledge System |
| **02_Knowledge_Domain.md** | Documentation de la table `knowledge_domain` |
| **03_Knowledge_Domain_Keyword.md** | Table relation : mots-clés par domaine |
| **04_Knowledge_Topic.md** | Documentation de la table `knowledge_topic` |
| **05_Knowledge_Topic_Keyword.md** | Table relation : mots-clés par topic |
| **06_Knowledge_Content_Type.md** | Référentiel des types de contenus de connaissance |
| **07_Knowledge_Content.md** | Documentation de la table `knowledge_content` |
| **08_How_to_Add_Knowledge.md** | Guide pour ajouter de nouvelles connaissances |
| **09_How_AI_Should_Use_Knowledge.md** | Instructions d’utilisation spéciales pour IA |
| **10_Useful_Queries.md** | Requêtes essentielles pour exploiter le Knowledge System |
| **11_Conventions_and_Rules.md** | Règles internes Lyxal (naming, standards, quality) |
| **12_Roadmap_Evolution.md** | Roadmap d’évolution du Knowledge System |
| **13_Auto_Learning_Foundation.md** | Base du futur module d’auto-apprentissage IA |

---

## 🎯 Objectif

Ce pack permet :

- À un humain de comprendre et maintenir le système
- À une IA de s’entraîner et générer du contenu conforme
- D’unifier la connaissance et d’éliminer les incohérences
- D’assurer une montée en qualité continue de la documentation Lyxal et IA

---

## 🚀 Utilisation recommandée

1. Lire le fichier **01_Knowledge_Overview.md**
2. Consulter les tables selon besoin
3. Suivre **08_How_to_Add_Knowledge.md** pour enrichir
4. Pour IA : se référer à **09_How_AI_Should_Use_Knowledge.md**
