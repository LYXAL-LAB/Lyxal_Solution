# 👤 Utilisation du Knowledge System par les Humains

## 🎯 Objectif

Ce document explique **comment les utilisateurs humains** (développeurs, membres de l’équipe Lyxal, apprenants, contributeurs, formateurs) doivent utiliser le Knowledge System pour :

- apprendre efficacement,
- naviguer et trouver l’information utile,
- contribuer à l’enrichissement du savoir,
- garder une cohérence globale dans le temps.

Ce guide complète celui destiné aux IA.

---

## 🧠 1. Pourquoi un Knowledge System ?

Le Knowledge System permet :

✅ d'apprendre plus vite  
✅ avec des informations **vérifiées et structurées**  
✅ en évitant les erreurs déjà connues  
✅ en devenant autonome sur l’écosystème Lyxal  

Il sert à la fois de :

- documentation intelligente,
- base de formation,
- aide contextuelle dans les outils Lyxal,
- référence interne pour normes et standardisation.

---

## 🧭 2. Navigation recommandée

L’humain doit naviguer selon ce parcours logique :

1. **Choisir un Domaine**  
   Exemple : SurrealDB, Business, IA, Lyxal Architecture.

2. **Sélectionner un Topic dans ce domaine**  
   Exemple dans SurrealDB : DEFINE TABLE, RELATE, INDEX FULLTEXT, PERMISSIONS.

3. **Explorer les Contenus associés**  
   Plusieurs types existent pour s’adapter au niveau et au besoin.

---

## 📚 3. Types de contenus et quand les utiliser

| Type de contenu | À utiliser si vous voulez… |
|---------------------|--------------------------------|
| **SYNTAX** | Voir la syntaxe correcte immédiatement |
| **RULE** | Comprendre les règles, contraintes, bonnes pratiques |
| **EXAMPLE_CORRECT** | Voir un exemple valide et copiable |
| **EXAMPLE_INCORRECT** | Éviter les erreurs courantes |
| **TIP** | Obtenir un conseil court et utile |
| **PATTERN** | Utiliser un modèle préconstruit et réutilisable |
| **EXPLANATION** | Comprendre en profondeur le sujet |

L’humain peut naviguer librement entre ces niveaux selon son besoin ou son niveau.

---

## 🪜 4. Parcours d’apprentissage recommandé

### 🟢 Débutant

1. Lire **EXPLANATION**
2. Étudier **EXAMPLE_CORRECT**
3. Tester
4. Lire **TIP** pour progresser

### 🟡 Intermédiaire

1. Lire **RULE**
2. Étudier **PATTERN**
3. Tester sur un cas réel
4. Lire **EXAMPLE_INCORRECT** pour éviter les pièges

### 🔴 Avancé / Expert

1. Combiner plusieurs **PATTERN**
2. Créer ses propres variantes
3. Contribuer au Knowledge pour améliorer la qualité

---

## 🔍 5. Comment rechercher efficacement

Trois méthodes :

### 1. Par domaine → topic → contenus  
Navigation logique, idéale pour apprendre.

### 2. Par mots-clés  
Utile quand on sait ce qu’on cherche (ex: “permissions”, “assert”).

### 3. Par type de contenu  
Idéal si vous voulez uniquement des exemples ou des patterns.

---

## ✍️ 6. Contribution au Knowledge System

Un humain peut proposer :

| Type de contribution | Description |
|--------------------------|----------------|
| Nouveau contenu | Ajouter un exemple, tip, règle, pattern |
| Correction | Améliorer une explication ou syntaxe |
| Amélioration IA | Ajuster la priorité, niveau ou use case |
| Organisation | Ajouter tags, keywords, liens |

> Toute contribution doit respecter la structure existante, pour conserver la qualité et la cohérence.

---

## ⚠️ 7. Règles d’or d’utilisation

| Règle | Pourquoi |
|---------|------------|
| Ne jamais modifier le schéma | Cohérence et compatibilité IA |
| Ne pas dupliquer un contenu | Le système doit rester propre et non redondant |
| Préférer enrichir plutôt que remplacer | Historique et progression conservés |
| Toujours tester les exemples | Prévenir les erreurs |

---

## 🚀 8. Ce que le Knowledge System apporte au quotidien

### Pour les développeurs

- réponses rapides,
- normes internes,
- base de code prête à l’emploi.

### Pour les formateurs

- support pédagogique structuré,
- niveaux adaptés par type de contenu.

### Pour les nouveaux arrivants

- onboarding autonome,
- montée en compétence accélérée.

### Pour Lyxal

- cohérence totale entre modules, IA, UI, docs, architecture.

---

## 🧵 Résumé

Le Knowledge System est conçu pour :

- faciliter l’apprentissage,
- éviter les erreurs,
- accélérer la productivité,
- rendre chacun plus autonome.

Ce n’est pas seulement une documentation :  
c’est **une base de connaissance vivante, structurée, évolutive**, utilisée par l'humain **et** par l’IA.
