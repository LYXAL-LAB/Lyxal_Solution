# 🎨 LyxalKitUI - Documentation Centralisée

**LyxalKitUI** est la bibliothèque UI centrale de l'écosystème LyxalSuite, basée sur DaisyUI 5 et Tailwind CSS 4. Elle fournit un système de composants, de thèmes et de layouts pour la génération automatique de SaaS.
