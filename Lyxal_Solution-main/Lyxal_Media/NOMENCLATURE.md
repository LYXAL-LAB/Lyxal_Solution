# Nomenclature Sémantique des Icônes Lyxal

Pour garantir l'indépendance vis-à-vis des packs techniques (Lucide, Tabler...), nous utilisons une nomenclature **fonctionnelle** pour les clés du dictionnaire (`icon_dictionary`).

Format : `[catégorie]_[sous-catégorie]_[nom]`

## 1. Actions (`action_`)
Utilisées pour les boutons, liens d'action et menus contextuels.

- `action_add` (Plus, Create)
- `action_edit` (Pencil, Pen)
- `action_delete` (Trash, Bin)
- `action_save` (Floppy, Disc, Check)
- `action_cancel` (X, Close)
- `action_search` (Magnifier)
- `action_filter` (Funnel)
- `action_sort` (Arrow Up/Down)
- `action_download` (Arrow Down Bar)
- `action_upload` (Arrow Up Bar)
- `action_share` (Share Node)
- `action_print` (Printer)
- `action_copy` (Copy, Duplicate)
- `action_refresh` (Rotate, Reload)
- `action_login` (Log In)
- `action_logout` (Log Out)

## 2. Navigation (`nav_`)
Utilisées pour la barre latérale, le header, les onglets.

- `nav_home` (House, Dashboard)
- `nav_settings` (Cog, Gear)
- `nav_profile` (User Circle)
- `nav_notifications` (Bell)
- `nav_messages` (Mail, Chat)
- `nav_calendar` (Calendar)
- `nav_menu` (Hamburger)
- `nav_back` (Arrow Left)
- `nav_next` (Arrow Right)
- `nav_more` (Dots)

## 3. Objets Métier (`obj_`)
Représentent une entité de la base de données.

- `obj_user` (User, Person)
- `obj_group` (Users, Team)
- `obj_file` (File, Document)
- `obj_folder` (Folder)
- `obj_image` (Image, Picture)
- `obj_video` (Video, Camera)
- `obj_product` (Box, Package, Tag)
- `obj_cart` (Shopping Cart)
- `obj_credit_card` (Credit Card)
- `obj_chart` (Bar Chart, Line Chart)

## 4. Statuts & Feedback (`status_`)
Utilisées pour les alertes, toasts, badges.

- `status_info` (Info Circle)
- `status_success` (Check Circle)
- `status_warning` (Alert Triangle)
- `status_error` (X Circle, Ban)
- `status_help` (Question Mark)
- `status_locked` (Lock)
- `status_unlocked` (Unlock)
- `status_visible` (Eye)
- `status_hidden` (Eye Off)

## 5. UI & Mise en page (`ui_`)
Éléments purement décoratifs ou structurels.

- `ui_chevron_down`
- `ui_chevron_up`
- `ui_chevron_left`
- `ui_chevron_right`
- `ui_drag_handle` (Grip)
- `ui_check_box_on`
- `ui_check_box_off`
- `ui_radio_on`
- `ui_radio_off`

## 6. Social & Marques (`brand_`)
Logos tiers.

- `brand_google`
- `brand_facebook`
- `brand_twitter` (X)
- `brand_github`
