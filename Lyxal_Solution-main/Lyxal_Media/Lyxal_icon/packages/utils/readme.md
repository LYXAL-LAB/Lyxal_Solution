# Lyxal Utils

This is a set of helper functions that deal with Lyxal icon sets.

Functions are split into a separate library because they are reused in many projects.

## Installation

To install the library run this command:

```
npm install @Lyxal/utils --save
```

## Documentation

Documentation is available at [Lyxal documentation website](https://Lyxal.design/docs/libraries/utils/).
