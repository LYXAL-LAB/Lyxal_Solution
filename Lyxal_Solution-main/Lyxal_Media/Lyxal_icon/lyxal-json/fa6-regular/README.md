# Font Awesome 6 Regular

This package contains icon data for Font Awesome 6 Regular icon set.

Files:

-   Icon data is stored in `icons.json` in `LyxalJSON` format. See [LyxalJSON documentation](https://lyxal.design/docs/types/lyxal-icon-json.html).
-   Icon set information is stored in `info.json` in `LyxalInfo` format. See [LyxalInfo documentation](https://lyxal.design/docs/types/lyxal-icon-info.html).

## Installation

```bash
npm install @lyxal-icon/fa6-regular --save-dev
```

## Usage

Icon data can be used with many tools and components, see [Lyxal documentation](https://lyxal.design/docs/usage/).

To convert to SVG, you can use [Lyxal Utils](https://lyxal.design/docs/libraries/utils/examples/export-svgs-from-icon-set.html) for basic usage or [Lyxal Tools](https://lyxal.design/docs/libraries/tools/).
