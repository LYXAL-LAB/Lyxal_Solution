# 📚 Lyxal Knowledge System – Documentation Index

Ce dossier contient l’ensemble de la documentation du **Knowledge System** utilisé dans l’écosystème Lyxal.  
Il définit comment les connaissances sont structurées, stockées, enrichies, utilisées par les humains et par les IA.

## 🎯 Objectif

Ce pack permet :

- À un humain de comprendre et maintenir le système
- À une IA de s’entraîner et générer du contenu conforme
- D’unifier la connaissance et d’éliminer les incohérences
- D’assurer une montée en qualité continue de la documentation Lyxal et IA

---

## 🚀 Utilisation recommandée

1. Lire le fichier **01_Knowledge_Overview.md**
2. Consulter les tables selon besoin
3. Suivre **08_How_to_Add_Knowledge.md** pour enrichir
4. Pour IA : se référer à **09_How_AI_Should_Use_Knowledge.md**
