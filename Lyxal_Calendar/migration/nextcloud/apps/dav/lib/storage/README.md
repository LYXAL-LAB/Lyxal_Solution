# Analyse du Répertoire `Storage` de Nextcloud DAV

Ce répertoire contient les wrappers de stockage (2 fichiers).

---

## `PublicOwnerWrapper.php`
-   **Fonction** : Wrapper de stockage pour les partages publics
-   **Usage** : Définit le propriétaire pour les fichiers partagés publiquement

## `PublicShareWrapper.php`
-   **Fonction** : Wrapper de stockage pour les partages publics
-   **Usage** : Gère les permissions et l'accès aux partages publics
