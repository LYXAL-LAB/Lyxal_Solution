# Analyse du Répertoire `Settings` de Nextcloud DAV

Ce répertoire contient les pages de paramètres (4 fichiers).

---

## Paramètres Utilisateur

### `AvailabilitySettings.php`
-   **Section** : Paramètres personnels
-   **Fonction** : Configuration des heures de disponibilité (VAVAILABILITY)
-   **Usage** : Définir les plages horaires où l'utilisateur est disponible

### `CalDAVSettings.php`
-   **Section** : Paramètres personnels
-   **Fonction** : Configuration CalDAV (synchronisation, notifications)

### `ExampleContentSettings.php`
-   **Section** : Paramètres personnels
-   **Fonction** : Afficher/masquer le contenu d'exemple

---

## Paramètres Admin (`Admin/`)

### `SystemAddressBookSettings.php`
-   **Section** : Paramètres d'administration
-   **Fonction** : Configuration du carnet d'adresses système
-   **Options** : Activer/désactiver la synchronisation
