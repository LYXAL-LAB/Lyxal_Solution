# Données embarquées de `lyxal_auth`

`common_passwords.txt` : mots de passe divulgués les plus courants (8 caractères ou plus, en
minuscules, sans doublon), refusés par la politique de mot de passe (`AUTH_PASSWORD_COMPROMISED`).
Source : liste « 100k most used passwords » du NCSC britannique (issue de Have I Been Pwned),
distribuée par SecLists (`Passwords/Common-Credentials/100k-most-used-passwords-NCSC.txt`),
licence MIT, Copyright (c) 2018 Daniel Miessler.
